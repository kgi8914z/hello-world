# 칩렛(Chiplet) 기술 개요 슬라이드

- `chiplet-overview.pptx` — 발표자료 본편 (16:9, 10장, 발표자 노트 포함)
- `chiplet-overview.gen.js` — 위 pptx를 만드는 생성 스크립트

내용을 고칠 때는 pptx를 직접 편집해도 되고, 스크립트를 고쳐 다시 생성해도 된다.
모든 도식은 이미지가 아니라 PowerPoint 도형이라 파워포인트에서 그대로 편집된다.

## 다시 생성하기

```bash
npm install pptxgenjs
node chiplet-overview.gen.js
```

## 구성

| 1 | 표지 | 2.5D 패키지 단면 도식 |

| 3 | 칩렛이란 | 모놀리식 SoC vs 분할 다이 비교 도식 |

| 6 | 패키징 기술 | 2D / 2.5D / EMIB / 하이브리드 본딩 단면 4종 |
